# StudyMate – Study Planner & Tracker

## Introduction
StudyMate is a simple Python-based study planner that runs in the terminal. It helps students create and manage study tasks and track their progress.

## Objectives
- Create study tasks
- View saved tasks
- Mark tasks as completed
- Track study progress
- Search tasks by subject
- Delete tasks

## Technologies Used
- Python 3
- JSON
- VS Code

## Python Concepts Used
- Variables
- Lists
- Dictionaries
- Functions
- Loops
- Conditional statements
- User input
- File handling
- Exception handling

## Features
1. Add Study Task
2. View All Tasks
3. Mark Task as Completed
4. Show Progress
5. Search Subject
6. Delete Task

## Data Storage
StudyMate stores study tasks in the study_data.json file so that the tasks remain saved after closing the program.

## Conclusion
StudyMate is a simple project that demonstrates the practical use of basic Python programming concepts for managing study tasks.
