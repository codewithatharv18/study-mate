# StudyMate – Study Planner & Tracker

StudyMate is a simple Python-based study planner that runs in the terminal.

It helps students manage their study tasks and keep track of their progress.

## Features

- Add Study Task
- View All Tasks
- Mark Task as Completed
- Show Study Progress
- Search Subject
- Delete Task
- Save tasks automatically

## Technologies Used

- Python 3
- JSON
- VS Code

## Project Structure

StudyMate/
├── main.py
├── study_data.json
└── README.md

## How to Run

1. Open the StudyMate folder in VS Code.
2. Open the terminal.
3. Run:

python3 main.py

4. The StudyMate menu will appear.
5. Select an option by entering its number.

## Data Storage

The study tasks are stored in the study_data.json file.

This means the tasks remain saved even after the program is closed.

## Main Menu

1. Add Study Task
2. View All Tasks
3. Mark Task as Completed
4. Show Progress
5. Search Subject
6. Delete Task
7. Exit
